# 画线规范

这份规范约束“图怎么画”，不重新定义缠论。结构字段的含义见
[`chanlun-primer.md`](chanlun-primer.md)，输入字段见
[`analysis-json.md`](analysis-json.md)。

## 1. 画布

- 单面板和三级面板都使用纵向堆叠；每个级别独立坐标轴，不共享价格轴。
- 默认宽度 1200px，面板高度 390px；窄屏可降到 720px。
- K 线数量超过 260 根时，`--mode auto` 自动切换为收盘线；需要蜡烛图时显式传
  `--mode candle`。
- 画布只表达已完成的历史结构。不要添加向右延伸的预测线、箭头、目标框或收益区间。

## 2. 图层顺序

从底到顶固定为：

1. 面板背景与网格；
2. 蜡烛或收盘线；
3. 中枢矩形；
4. P2 线段（如有）；
5. 笔折线与端点；
6. 分型标记；
7. 力度背离候选、P4 结构段与 A 类位置；
8. 文字标签。

中枢必须在 K 线之上、笔之下，避免遮住笔端点。文字标签不得压住轴刻度或面板标题。

## 3. 符号语义

| 图元 | 含义 | 约束 |
|---|---|---|
| 蜡烛/收盘线 | 原始价格轨迹 | 不代替结构；只作参照 |
| 蓝色实线 | 笔 | 连接顶底分型端点；不画预测延伸 |
| 蓝色圆点 | 笔端点 | 与笔折线同层，半径 3–4px |
| 粗半透明线 | P2 线段 | 确认段实线、未确认段虚线；不得替代 strict 笔 |
| 琥珀虚线框 | 中枢 | 横向覆盖 `start_date → end_date`，纵向覆盖 `ZD → ZG` |
| 红色上三角 | 顶分型 | 置于最高价上方；默认只画笔端点分型 |
| 绿色下三角 | 底分型 | 置于最低价下方；默认只画笔端点分型 |
| 紫色菱形 | 背离/背驰候选 | 没有趋势时只写“背离候选” |
| 紫色空心菱形 | P4 结构段 | 标签写中性结构状态；`sub_status=unknown` 时附“次级别缺失” |
| 青色圆环 | A 类结构位置 | 文案写“A 类候选”；完整解释放图例 |

颜色是辅助，语义必须同时由形状和标签表达。打印成灰度图时仍应能区分：
虚线框 `stroke-dasharray`、菱形、圆环、三角形。

## 4. 颜色与主题

- `--theme light`：白底，适合 Obsidian/网页/论文。
- `--theme dark`：深底，适合暗色界面。
- `--palette cn`：红涨绿跌，默认。
- `--palette intl`：绿涨红跌。
- 颜色只用于区分图元，不用颜色暗示看多/看空。

## 5. 标签与避让

- 中枢标签格式：`ZG 4299.6 / ZD 4197.8`，不要写“支撑/压力”。
- 背离标签只保留最近一个，其余用菱形表示，避免在密集区域堆字。
- P4 结构段只画最近一个；`随时结束` 映射为“高幅度比”，`中枢背离段失败` 映射为“回中枢”，
  `走势背离段失败` 映射为“破 p0”，避免把结构状态写成价格预测。
- 靠近右边界时标签改为右对齐，不得越出画布。
- 多面板标题写级别（日线/60分/30分），副标题写结构来源与 K 线数。
- 图例固定写：`实线=笔｜虚线框=中枢｜实心菱形=背离候选｜空心菱形=P4结构段｜圆环=A类结构位置（形态）`。

## 6. 多级别规则

- 日线、60 分、30 分各自一个面板；面板顺序从大到小。
- 每个面板独立计算坐标范围，不把不同价格尺度的线叠加。
- 可在总标题写标的名，但不要在面板之间画跨级别的“推导箭头”。
- 级别口径不一致时，在副标题或交付说明中注明数据源；不要静默混用真身与代理。

## 7. 验收清单

- [ ] SVG 可以被浏览器/Quick Look 打开。
- [ ] 标题、轴刻度、图例、页脚没有越界。
- [ ] 至少存在一个 `data-layer="hub"` 或明确说明“无中枢”。
- [ ] 笔折线端点与 `bis` 的顶底价格一致；有索引时检查相邻笔首尾相接。
- [ ] 有 `segment_analysis` 时，线段端点价格与 `start_price/end_price` 一致，确认状态可区分。
- [ ] 中枢矩形覆盖 `ZD → ZG`，不是随意画的水平带。
- [ ] 分型/信号标签没有大面积重叠；密集时已切 `--fractals endpoints`。
- [ ] 页脚保留“仅形态结构标注，不构成投资建议”。
- [ ] `p4_divergence.sub_status=unknown` 时图中明示“次级别缺失”。
- [ ] 没有预测箭头、目标价、仓位或操作指令。
