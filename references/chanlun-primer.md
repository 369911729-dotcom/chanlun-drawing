# 缠论画线速查

本页只保留画图必需的几何概念。定义冲突时，以 `chanlun-obays` 引用的 108 课定义层为准；
形态判读再看和干体系。深入推导请读
`chanlun-obays/references/chanlun-theory.md` 与
`chanlun-obays/references/chanlun-108-theorems.md`。

## 1. 包含处理

相邻 K 线出现包含关系时先合并：

- 向上处理：高点取较高者，低点取较高者；
- 向下处理：高点取较低者，低点取较低者；
- 合并后的新 K 线继续与下一根比较，不能对原始 K 线跳步。

画图时用原始 K 线展示价格，用合并序列确定分型；不要把合并 K 线的索引直接当原始 K 线索引。

## 2. 分型

相邻三根合并 K 线：

- 中间一根高点最高、低点也最高 → 顶分型；
- 中间一根低点最低、高点也最低 → 底分型。

## 3. 笔

- 顶分型与底分型交替；
- 两个分型之间至少有一根独立 K 线；
- 图中用端点日期和价格连线；
- 不把“间隔不足的局部转折”硬画成笔。

`chanlun-obays` v2.9.4 起使用 strict 笔链：同向端点只保留更极端者，异向端点间隔达标才成笔；
更极端端点前移时同步回写上一笔终点，使 `bis[i].end_index == bis[i+1].start_index`。
画线器不通过删除相邻同向笔来“美化”结构。

## 4. 线段与中枢

- 线段至少三笔，前三笔有重叠；正式划分还应检查特征序列。
- 中枢是连续三段次级别走势的重叠区间，画成 `ZD → ZG` 的矩形。
- 中枢延伸保持原区间；离开段不再画进矩形。
- 奔走、标准、扩大、收敛是形态提示，画图时写“疑似”而不是确定结论。
- `chanlun-obays --segment-engine p2` 是可选线段引擎；确认段才可作为线段级结构展示，
  无确认段时继续使用 strict 笔中枢。

## 5. 走势与力度

- 方向层：上涨 / 下跌 / 盘整；
- 结构层：盘整 / 延伸 / 扩张 / 扩展 / 趋势；
- 两个同级别中枢无重叠才是趋势；
- 离开段幅度大于进入段是趋势形成的充分条件，不是未来预测。

## 6. 背离与背驰

- **背离**：中枢角度，可能变异；没有新低/新高就没有新的背离段；
- **背驰**：趋势角度，必须有趋势前提；
- MACD 面积只作力度辅助；
- 图上没有趋势证据时，标签写“背离候选”，不要写“背驰成立”。
- P4 用幅度比、次级别同向中枢和中枢/走势类型作结构判定；`sub_status=unknown` 时只记录
  “次级别缺失”，不确认扩展、变异或走势结束。

## 7. A 类结构位置

- A₁ / A₂ / A₃ 是中枢形态维度的结构位置；
- 一 / 二 / 三类是位置维度的分类；
- A₃ 与收敛中枢不确定性高；
- 图中统一写“A 类候选”或“A 类结构位置（形态）”，不写操作指令；
- 页脚必须声明：仅形态结构标注，不构成投资建议。

## 8. 画图前检查

1. 数据是否按时间升序、是否跨日？
2. 级别是否由用户指定，而不是脚本猜？
3. 结构 JSON 与 K 线是否来自同一标的、同一时间窗？
4. 中枢矩形是否真的落在连续三笔的重叠区？
5. 背离标签是否有新低/新高与力度衰减支撑？
6. 多级别是否各用独立坐标轴，没有混用真身与代理？
